# CGS Verification Register

Status: Phase 0 verification sprint
Last reviewed: 21 September 2026

This register separates verified institutional facts from website assumptions and editorial groupings. It should be updated whenever CGS or NSUK supplies stronger evidence.

## Confidence levels

- **A — Official current source:** current NSUK/NSUK SPGS/LMS material
- **B — Official historical source:** official NSUK material, but older or not sufficient to prove current status
- **C — Strong recent secondary source:** recent reputable reporting or current public professional profile
- **D — Centre-supplied project material:** supplied directly for the website but not independently public/verified
- **E — Editorial / unverified:** useful working copy or classification, but not established institutional fact
